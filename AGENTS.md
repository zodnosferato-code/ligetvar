# Agent entry point

Read [AGENT.md](AGENT.md) in full before working in this repository. It is the maintained contributor guide; this file is a discovery entry point, not a second rule set.

In particular, follow its [archives and refactor workflow](AGENT.md#archives-and-refactor-workflow), the [current design index](docs/design/README.md), [single tracker](docs/design/TRACKER.md), and [narrative workflow](docs/design/NARRATIVE-WORKFLOW.md). Retired files under [docs/archive/](docs/archive/README.md) are historical, not active requirements.

**For story-engine and asset-related tasks, work off the [master tracker](docs/design/MASTER-TRACKER.md).** It is the consolidated, prioritized working list for those areas (story writing depth, INT2 annual arcs, localization, staging, seasonal outfits/backgrounds, character art gaps, etc.). Treat its IDs, priorities and remaining gates as the current task set. Update the master tracker together with `docs/design/TRACKER.md` and any owning contracts in the same commit as the work.

For the next story/dialogue task, follow the [individual-story and elapsed-time handoff](docs/design/NARRATIVE-WORKFLOW.md#next-agent-brief--individual-stories-elapsed-time-and-slow-cli-review): small implementation batches, character/plot continuity, actual calendar dates, and CLI playtesting before and after each rewrite.
