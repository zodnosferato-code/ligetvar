# Karakter képi assetek

**Megjegyzés:** Az összes kép (referencia, intim, háttér, ikon) el lett távolítva a repóból a kérés szerint. A vizuális leírások a dokumentációban (04-vizualis-biblia.md, 11-kepgeneralasi-szabaly.md, 23-teljes-test-referencia.md, 33-kepgeneralo-promptok.md) vannak részletezve, hogy AI képgeneráló eszközök konzisztensen reprodukálhassák a karaktereket.

A jelenetek a játékos első személyű nézőpontjából (POV) vannak. A leírások tartalmazzák a helyszíneket is.

Új képek generálásakor mindig a zárt stílus-sablont és a pontos karakterblokkokat használd.
