# Archived assets

> **Status:** Archive index. | **Purpose:** Explain archived assets and their non-runtime status.

This folder contains historical artwork and review notes that are not used by the game runtime. See the [full archived asset inventory](INVENTORY.md) for the file list.

- `references/intim/` holds 126 legacy reference files, including two upload-test text files. It is retained for provenance only.
- `characters/` holds 18 retired character images plus prior locks, generation prompts, and notes. These are not current design templates.
- `IMAGE_ASSET_LOG-2026-10-16.md` documents the prior pixel-art direction and is historical only.

Active game images are listed in `src/game/content/assets.ts`; backgrounds remain under `assets/backgrounds/`. Do not import archived files into runtime content without review and approval.
