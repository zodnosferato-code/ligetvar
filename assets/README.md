# Game assets

The active image manifest is `src/game/content/assets.ts`. The current location backgrounds are kept under `backgrounds/`; their atmosphere is the accepted baseline. The player-facing scene framing should feel like the player is present, with a natural place for the character to sit opposite them.

Character and background art are transitional. The requested direction is detailed, non-pixel anime illustration; final rendering and composition rules are still being defined in [the art register](../docs/ART-REGISTER.md).

Historical, non-runtime assets and the superseded 2026-10-16 pixel-art review log are retained under [archive/](archive/).
